# 🌸 Mother's Day Tribute

A modern, emotional, and heartfelt tribute website dedicated to mothers everywhere—especially in loving memory of my late mother. This project is handcrafted to be simple, peaceful, and deeply personal.

> “May Allah increase my mother’s ranks in Jannah. 🤍 She passed away a year ago, but her love still lives in every heartbeat.”

---

## ✨ Features

- **Heartfelt Hero Section**: Featuring a warm illustration and a cinematic opening tribute.
- **Tribute Cards**: Simple, elegant cards reflecting the essence of a mother (Love, Care, Support, etc.).
- **Sacrifice Timeline**: A dedicated section honoring the silent battles and selfless acts of mothers.
- **Memory Upload**: An interactive space for users to upload and preview their favorite childhood memories.
- **Peaceful Prayer Section**: A closing section with heartfelt duas and blessings for mothers.
- **Responsive & Modern UI**: Built with a "human-first" design philosophy, focusing on soft colors, emotional typography, and smooth transitions.

## 🛠️ Tech Stack

- **Frontend**: [React JS](https://reactjs.org/) (Functional Components & Hooks)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) for smooth reveals and hover effects.
- **Icons**: [Lucide React](https://lucide.dev/) for clean, functional iconography.
- **Styling**: Vanilla CSS with custom theme variables for a warm, soft aesthetic.
- **Image Generation**: Custom AI-generated illustrations for a unique, emotional feel.

## 🚀 Getting Started

Follow these steps to run the project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AhmedRaza186/mothers-day-tribute.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd mothers-day-tribute
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```

5. **Open in your browser**:
   Navigate to `http://localhost:5173` (or the port shown in your terminal).

## 🎨 Design Philosophy

This website was redesigned to move away from "overdesigned" futuristic aesthetics. Instead, it embraces:
- **Simplicity**: Clean layouts that even a mother could easily navigate.
- **Warmth**: A soft pink and white color palette that feels cozy and respectful.
- **Emotion**: Using serif typography (`Playfair Display`) to convey a sense of elegance and storytelling.
- **Human Touch**: Designed to feel like it was made by a son for his mother, not by an AI for a competition.
